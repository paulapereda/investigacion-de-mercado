Bloque 1
¿Qué es LaTeX y qué es Overleaf?
  • LaTeX es un sistema de composición tipográfica: el autor escribe contenido y estructura; LaTeX genera el formato. Se usa en investigación académica, economía, estadística e ingeniería en todo el mundo
  • Overleaf es un editor de LaTeX en el navegador — sin instalación, con vista previa en tiempo real, con historial de versiones y colaboración simultánea
  • La cuenta gratuita de Overleaf es suficiente para todo el trabajo del curso: ilimitados proyectos, compilación en tiempo real, plantillas disponibles

\documentclass[12pt, a4paper]{article}

% — Cuerpo del documento — \begin{document} \maketitle
Aquí va el contenido del informe.
\end{document}
Todo lo que está antes de \begin{document} es el preámbulo: se configura ahí, no aparece en el PDF. Todo lo que está dentro es lo que el lector ve.

Bloque 2 — Profundización
Listas: itemize vs enumerate
Viñetas — itemize
\begin{itemize} \item Primer punto \item Segundo punto \begin{itemize} % anidada \item Sub-punto \end{itemize} \end{itemize}
Numerada — enumerate
\usepackage{enumitem} % preámbulo
\begin{enumerate}[label=\alph*.] \item a. Primer ítem \item b. Segundo ítem \end{enumerate}
% Otros label: \arabic*, \roman*, \Alph*
Parámetro de label Resultado Ejemplo de uso
\arabic*1, 2, 3…Pasos de un proceso
\alph*a, b, c…Opciones de respuesta en cuestionario
\roman*i, ii, iii…Secciones de metodología
\Alph*A, B, C…Alternativas en instrumentos

Bloque 3 — Imágenes en detalle
Múltiples imágenes en un mismo flotante
\usepackage{subcaption} % en el preámbulo
\begin{figure}[H] \centering \begin{subfigure}[b]{0.45\textwidth} \includegraphics[width=\textwidth]{grafico_hombres.png} \caption{Segmento masculino} \end{subfigure} \hfill % espacio entre subfiguras \begin{subfigure}[b]{0.45\textwidth} \includegraphics[width=\textwidth]{grafico_mujeres.png} \caption{Segmento femenino} \end{subfigure} \caption{Frecuencia de compra por segmento de género} \end{figure}
Cuándo usar subfiguras
Ideal para comparar segmentos (género, edad, canal) o mostrar el antes/después de un insight. La leyenda de cada subfigura lleva letra automaticamente: (a), (b), (c)…
Bloque 3 — Tablas avanzadas
Generadores automáticos: evitar escribir tablas a mano

Anatomía de una tabla booktabs bien hecha
\toprule — línea gruesa inicial
Fila de encabezados (en negrita, \textbf)
\midrule — línea delgada bajo el encabezado
Filas de datos (separadas por \\)
\bottomrule — línea gruesa final
Sin líneas verticales — el estándar APA y académico

Bloque 3b — Ecuaciones
Múltiples ecuaciones: align y gather
align — alinea por el signo =
\usepackage{amsmath} % preámbulo
\begin{align} H_0 &: \mu_1 = \mu_2 \\ H_1 &: \mu_1 \neq \mu_2 \end{align}
gather — centradas, sin alinear
\begin{gather} NPS = \%Promotores - \%Detractores \\ NPS \in [-100,\ 100] \end{gather}
EntornoCuándo usarloNumeración
equationUna sola fórmula destacadaUn número por bloque
alignPasos derivados, hipótesis H₀/H₁Un número por línea
gatherVarias fórmulas sin relación directaUn número por línea
equation*Fórmula sin numerarSin número

Bloque 3c — Variables y funciones
Variables con \def — un cambio, muchos lugares
% Definir variables en el preámbulo: \def\empresa{Mercado Libre Uruguay} \def\entrega{Segunda entrega} \def\nmuestra{385} \def\ancho{0.7\textwidth}
% Usar en el documento: Esta investigación analiza el caso de \empresa. La muestra corresponde a $n = \nmuestra$ usuarios.
\begin{figure}[H] \includegraphics[\ancho]{grafico.png} \end{figure}
Por qué usar variables
Si el nombre de la empresa cambia, el tamaño muestral se actualiza, o se reutiliza la plantilla para otra entrega: se cambia en un solo lugar del preámbulo y LaTeX actualiza todo el documento automáticamente. La plantilla del curso ya usa este patrón con \nombreentrega.
Bloque 3c — Variables y funciones
Funciones con \newcommand — reutilizar estructuras complejas
% Función para insertar figura con parámetros: % #1 = archivo, #2 = ancho, #3 = epígrafe, #4 = label \newcommand{\mifigura}[4]{ \begin{figure}[H] \centering \includegraphics[width=#2]{#1} \caption{#3} \label{fig:#4} \end{figure} }
% Usarla en el documento: \mifigura{grafico_nps.png}{0.8\textwidth}{Evolución del NPS — 2022–2024}{nps} \mifigura{mapa_calor.png}{0.6\textwidth}{Mapa de calor por segmento}{calor}
Una función escribe el código repetitivo una sola vez. El Template-Informe de Overleaf que usamos en el curso ya define funciones como \portada con exactamente este mecanismo. Cuando necesiten algo que se repite 5 veces, vale la pena crear un \newcommand.

Bloque 3d — Capacidades avanzadas
Diagramas de flujo con TikZ
  • TikZ (paquete tikz) permite dibujar cualquier figura vectorial con código: diagramas de flujo, árboles de decisión, grafos, mapas de proceso. El resultado es tipográficamente perfecto y escala sin perder calidad
  • Para investigación de mercado: útil para diagramar el proceso de muestreo, el Customer Decision Journey, o el diseño del cuestionario
  • La curva de aprendizaje es alta — para uso en el curso se recomienda empezar con plantillas de texample.net/tikz y adaptar
\usepackage{tikz} \usetikzlibrary{shapes, arrows.meta}
\begin{tikzpicture} \node (inicio) [draw, rounded corners] {Problema de investigación}; \node (diseño) [draw, below=of inicio] {Diseño del estudio}; \draw [->] (inicio) -- (diseño); \end{tikzpicture}
Alternativas más rápidas
Para la mayoría de los diagramas del curso conviene exportar como .png desde Canva, PowerPoint, o draw.io e insertarlo con \includegraphics. TikZ es poderoso pero costoso en tiempo de aprendizaje inicial.

Bloque 5 — Resumen final
LaTeX vs Word: cuándo usar cada uno
Seguí usando Word cuando…
El documento tiene menos de 3 páginas y no tiene fórmulas
Necesitás comentarios de revisión estilo track-changes
El cliente o destinatario necesita editar el .docx
No hay tablas, figuras numeradas ni bibliografía formal
Usá LaTeX cuando…
El informe tiene figuras numeradas, tablas y bibliografía
El PDF debe verse idéntico en cualquier computadora
Hay ecuaciones o notación estadística formal
Trabajás en equipo sobre el mismo documento (Overleaf Share)
El documento es una tesis, paper o entrega de curso formal
